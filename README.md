<h2 align="center">Featured Engineering Work</h2>01. PrepX — AI-Powered Online Exam & Practice Platform
Team Project (3 members)

Technology Stack: Python · Django · Django REST Framework · SQLite · Bootstrap · Chart.js · ReportLab · Gemini API

An online examination and practice platform combining role-based access, question management, AI-assisted learning, automated assessment, and teacher analytics.

Engineering Contributions
- Authentication and authorization: Implemented secure authentication, session management, route protection, and role-based access control (RBAC) for three roles: Student, Teacher, and Admin.
- Question bank APIs: Built Subject, Topic, and Question Bank REST APIs with Django REST Framework, including ownership controls, difficulty levels, validation, search, and filtering.
- AI-assisted learning: Integrated the Gemini API for AI-assisted question generation and personalized learning recommendations.
- Exam and practice workflows: Developed progressive test unlocking, timed exams, automatic saving, question randomization, negative marking, and automatic evaluation.
- Teacher tools and reporting: Built exam management features, analytics dashboards with Chart.js, certificate generation with ReportLab, and CSV/Excel exports, using Django ORM for data handling.
Repository: PrepX-Team/PrepX
02. SwarnaRatna — Jewelry Shop Management System
Personal Project

Technology Stack: Python · Django · Django REST Framework · MySQL · Bootstrap · Chart.js · ReportLab

A web-based jewelry shop management system covering role-specific operations, inventory, billing, customer records, and business analytics.

Engineering Contributions
- Role-based access control: Designed and implemented RBAC for Admin, Staff, and Customer roles using middleware, decorators, and template-level authorization checks.
- Inventory management: Built SKU tracking, metal and purity information management, stock deduction, low-stock alerts, and soft-delete protection.
- Billing and APIs: Developed Django REST Framework endpoints and a transactional billing workflow with dynamic pricing, GST calculation, automatic stock updates, and PDF invoice generation using ReportLab.
- Customer data isolation: Restricted customer access to their own orders, invoices, and repair information.
- Transaction integrity and security: Applied transaction.atomic(), CSRF protection, session security, and input validation to protect financial workflows.
- Analytics and reporting: Created sales, inventory, customer, and repair dashboards with CSV/Excel export, Django ORM, and optimized MySQL queries for faster report retrieval.
Repository: aniketbiradar-official/jewelry-shop-management
