<table>
<tr>

<td width="62%" valign="top">

## 🚀 Overview

ImageScraper is a modular automation pipeline built to demonstrate how modern data collection systems are engineered.

Rather than simply downloading images, the application focuses on reliability, maintainability, cloud integration, and scalable software architecture.

The project follows clean engineering principles including configuration management, layered architecture, centralized logging, exception handling, and database abstraction.

---

## ✨ Engineering Highlights

- 🤖 Automated browser interaction using **Selenium WebDriver**
- ☁️ **MongoDB Atlas + GridFS** integration for cloud storage
- 🔐 **SHA-256 checksum** based duplicate detection
- 🖼️ Automatic **WebP → JPG** conversion
- 📁 Topic-wise image organization
- ⚙️ Environment-based configuration using **.env**
- 📊 Centralized logging with rotating log files
- 🧹 Automatic filtering of low-quality and invalid images
- 💻 Production-ready CLI interface
- 🧩 Modular architecture with complete separation of concerns
